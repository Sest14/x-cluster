# 判定基準書（コードブック）

> 状態：**下書き**。ラベル付けの練習（20件ほど）をしたあとに見直して確定し、確定版をコミットしてから本番のラベル付けを始める。
> ラベルを付けるときは、どの件の検索から来た投稿かを伏せる。迷ったら「不明」にして、その理由をメモ欄に書く。
> アカウントのラベル（§B）は第2段階のアカウントに付ける。見るのはプロフィールと、炎上前（なければ直近）の投稿30件。

## A. 投稿のラベル（起点の投稿1件ごと）

### A1. 関連性
| ラベル | 基準 |
|---|---|
| 関連 | その件（作品、機能、商品名、裁判）そのもの、またはその件から始まった議論について述べている |
| 無関係 | 同じ語を含むが別の話（例：CPU のレジスタ、レジ打ちの話、無関係な BL の話題） |

### A2. 立場：表現規制の軸（regista／bl_zoning／uma_mune／edamame／touken）
| ラベル | 基準 | 例（言い換え） |
|---|---|---|
| 批判 | 対象の表現・作品・商品名を問題視している。規制・撤回・ゾーニングの強化を求めている。または「気持ち悪い」「有害」と評価している | 「未成年にこういう描写を向けるのは無理」「名前を変えるべき」 |
| 擁護 | 対象の表現を擁護している。規制に反対している。または批判する人たちを批判している | 「フィクションに口出しするな」「燃やす側が言いがかり」 |
| 対抗的な批判 | 対象の表現を問題視するのではなく、「それなら別ジャンルも同じ基準で規制しろ」と相手のジャンルを攻撃している（BL焼き払いなど） | 「レジスタがダメならBLも有害図書だ」 |
| 中立・報道 | 経緯の紹介、ニュースの共有、両論を並べている | 「〜が炎上しているらしい」 |
| 不明 | 皮肉か本気か判断できない。文脈がないとわからない | |

※「対抗的な批判」は、表現規制に賛成しているのか反対しているのか一概に言えないので、独立したラベルにする。

### A3. 立場：斉藤の件の軸（saito）
| ラベル | 基準 |
|---|---|
| 被害者寄り | 性加害を批判している。被害者を擁護している。量刑を支持している |
| 被告寄り | ハニートラップ説・冤罪説、被害者への疑い、被告の擁護 |
| 中立・報道 | 判決や求刑の事実の共有だけ |
| 不明 | 判断できない |

### A4. 対照群（control）
立場は付けない。関連性も付けない。§B のアカウントのラベルだけを付ける。

## B. アカウントのラベル（プロフィールと直近の投稿を見て1人ごと）

### B1. 運用の型
| ラベル | 基準 |
|---|---|
| 汎用型（日常垢・本垢運用） | 日常生活の話（食事、仕事・学校、体調、天気、外出など）が複数の話題にまたがって出てくる |
| 話題特化型（サブ垢） | 特定の話題（1つのジャンル、議論、愚痴など）がほとんどを占める。日常の話はほぼ出ない。またはプロフィールに用途が書かれている（「〇〇用」「議論垢」「避難垢」「愚痴垢」など） |
| 業務・公式・報道 | 企業、メディア、まとめ、宣伝、作家の告知専用など |
| bot・スパム | 自動投稿、同じ文の繰り返し、宣伝リンクばかり |
| 判断不能 | 取得できた投稿が少ない、鍵、日本語以外が大半など |

### B2. ジャンルの所属（複数選択可）
直近の投稿で繰り返し出てくるジャンルに印を付ける。例：刀剣乱舞、その他の女性向けジャンル（BL・乙女ゲーム・男性アイドル系など）、男性向けジャンル（美少女ゲーム・ウマ娘など）、どれにも当てはまらない。

### B3. メモ
迷った理由、判断の根拠を自由に書く。

## C. ラベル付けの手順（ADR-0012）
- 全件を Claude が自動で判定する。件名は伏せ、順番を混ぜる。1件ごとに確信度（高・中・低）を付ける。
- ユーザーは抜き取り検査（投稿60件、アカウント30件）と、確信度が低いもの（最大20件）の判断をする。
- 練習として、まずユーザーと Claude が同じ20件を判定して照らし合わせ、基準の読み違いを直してから基準書を確定する（この20件は精度の数字に入れない）。
- 途中で基準を変えたら、ADR を書き、それ以前のラベルを付け直す。
