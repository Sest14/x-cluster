## 1. 問い
1. 表現規制・男女論の炎上（2026年10〜11月）で発言しているアカウントは、ふだん何について発言しているか。
2. そのアカウントは、話題と関係ややり取りの面から、どのようなクラスタを作っているか。
3. そのアカウントのうち、話題特化型（サブ垢）と汎用型（日常垢・本垢運用）はそれぞれどれくらいの割合か。立場、件、対照群によって違いはあるか。
4. 刀剣乱舞をはじめとする女性向けジャンルの界隈に属するアカウントは、どのくらい関わっているか。

## 2. 仮説（2026-11-19、収集前に記録。外れても報告する）
| 番号 | 仮説（ユーザーの予想） | 検証のしかた |
|---|---|---|
| H1 | 表現を**批判する側**の本垢運用率は、**対照群より低い**（サブ垢・話題特化型が多い） | 批判側（codebook A2「批判」）と対照群の本垢運用率の差 |
| H2 | 表現を**擁護する側**の本垢運用率は、**批判する側より高い** | 擁護側（A2「擁護」）と批判側の本垢運用率の差 |
| H3 | 刀剣乱舞の界隈のアカウントは、**そもそも炎上に言及していない人が多い**（過半数） | 界隈のアカウント（touken_fans）のうち、調査期間中に5件のどれかに言及した人の割合。対照群と比べる（ADR-0013） |

H1・H2 の「批判側」「擁護側」は、表現規制の軸の5件（regista／bl_zoning／uma_mune／edamame／touken）をまとめ、起点の投稿の立場（codebook A2）で分ける。1人に複数の起点投稿があって立場が割れるときは、多いほうを採る（同数なら「不明」）。斉藤の件は軸が違うので含めない。比率は第1段階の判定を第2段階で補正し、抽出確率の重みをかけて出す。

斉藤の件、件ごとの違い、対抗的な批判（BL焼き払い）は、予想を立てない**探索的な分析**として扱う。そこで見つかった差は「仮説の候補」として報告し、結論にはしない。

### 「差がある」と言う基準（ADR-0013）
- 群の間の差について、推定値と95%信頼区間を出す。
- 信頼区間が0をまたがなければ「差がある」と言う。またぐ場合は「この規模のデータでは差があるとは言えない」と言う（「差がない」とは言わない）。
- 差の推定値が10ポイント未満なら「差はあるが小さい」と添える。
- H1〜H3 の3つの比較には多重比較の補正（ホルム法）をかける。

## 3. 母集団と収集条件（確定）
- データ源：投稿とプロフィールは TwexAPI、公式 X API は件数と網羅性の検査だけ（ADR-0014）
- 期間：2026-10-20 〜 収集日
- 言語：日本語（`lang:ja`）、RTは除く
- 起点の検索条件：`config.json` の `queries`（regista／bl_zoning／uma_mune／edamame／saito／touken／touken_fans／control）
- touken_fans：刀剣乱舞の語を含む投稿をした人（炎上との関係は問わない）。H3 の検証用（ADR-0013）
- 該当件数（2026-11-19 時点）：regista 22,206／bl_zoning 28,689／uma_mune 3,457／edamame 1,833／saito 13,521／touken 1,097
- 対照群：同じ期間に「の」を含む日本語投稿の投稿者（ADR-0010）

## 4. 抽出（確定。ADR-0014）
- 起点の投稿：6件は期間中の全件。touken_fans と対照群は日別比例で1,000件（ADR-0009）
- アカウント：各群200人を無作為抽出（合計1,600人、乱数シード42）。6件は全投稿者からの単純無作為抽出なので重みは不要。touken_fans と対照群は、該当投稿数の逆数で重み付けする
- ふだんの投稿：抽出した全員について、炎上前（2026-09-15〜10-15）の投稿を最大50件。炎上前の投稿がなければ直近30件
- 運用の型の第1段階判定：ADR-0011 のルール（事前登録。変更しない）。日常語の割合は取得した投稿から数える
- 第2段階（詳しい判定）：各群25人を、第1段階の判定で層に分けて選び、Claude が codebook B で判定する。これで第1段階ルールの的中率を測り、比率を補正する
- 追加の条件：第1段階ルールの的中率が70%未満なら、詳しい判定を各群25人追加する（追加の費用はほぼかからない）
- touken_fans と対照群：5件のどれかに言及したかを、TwexAPI の検索で確かめる（H3）

### 網羅性の検査（ADR-0014）
- 件ごと・日ごとに、TwexAPI の件数と公式の件数を比べる
- 件ごとに約100件、公式APIで無作為に取った投稿が TwexAPI の収集に含まれているかを照合する
- 見つかった割合が90%以上なら良好、80〜90%なら限界として明記、80%未満ならその件は参考値とし H1・H2 の検証に使わない
- 取れていた投稿と取れていなかった投稿で、返信・引用・メンションの割合を比べる

## 6. 除外基準（確定）
- bot・スパム、業務・公式・報道のアカウントは、本垢運用率の分母から除く（件数は別に報告する）
- 取得できた投稿が10件未満のアカウントは「判断不能」とする
- 起点の投稿が「無関係」と判定されたアカウントは、その件の集計から除く

## 7. 主に見る比較（確定）
- 確認的な比較（H1〜H3）：批判側と対照群、擁護側と批判側の本垢運用率。touken_fans の言及率（対照群と比べる）
- 探索的な比較：件ごとの本垢運用率、対抗的な批判の参加者の特徴、斉藤の件の立場ごとの特徴、立場ごとのクラスタ構成（話題とやり取り）

## 8. ラベルと精度（ADR-0012）
- Claude が判定基準書に沿って全件に自動でラベルを付ける（学習はさせない。ADR-0007）。件名は伏せ、順番を混ぜる。
- ユーザーが、層化して無作為に選んだ投稿60件とアカウント30件で抜き取り検査をする。自動判定の正解率とκを、群ごとに出す。
- 群の間で正解率の差が15ポイントを超えたら、群ごとに補正する。κが0.6未満なら判定基準書を直す。
- 自動判定で確信度が低いもののうち、最大20件はユーザーが判断する（精度の測定には使わない）。
