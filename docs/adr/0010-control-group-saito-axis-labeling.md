# ADR-0010: 対照群を置く。斉藤の件は別の軸で判定する。正解ラベルはユーザーが付ける

- 日付：2026-11-19
- 状態：一部置き換え（人数・予算は ADR-0011、正解ラベルの担当は ADR-0012 で置き換え。対照群と斉藤の軸は有効）

## 背景
- 「批判側のサブ垢率」のような数字は、一般のアカウントと比べないと意味がない（methodology.md §2.4）。
- ジャンポケ斉藤の件は性加害の裁判で、ほかの5件の「創作物の表現を規制すべきか」という対立とは軸が違う。
- 判定の精度を測るには、判定する側から独立した正解ラベルが必要。

## 決定
1. **対照群**：同じ期間に「の」を含む日本語投稿（RTを除く）を日別比例で250件集め、その投稿者から70人を無作為に選ぶ（`config.json` の `control`）。
2. **人数**：各件35人×6件＋対照群70人＝280人。起点の投稿は1件につき350件。
3. **予算**：上限165ドル（見積もりは約160ドル）。ユーザーは対照群込みで160ドル前後を選んだ。1日の最低取得件数による余分を含めて上限を5ドル上げた。
4. **斉藤の件**：立場を「被害者寄り（性加害を批判）／被告寄り（ハニトラ説・冤罪説など）／中立・報道／無関係」で判定する。表現規制の軸とは混ぜずに、別の集計にする。
5. **正解ラベル**：ユーザーが付ける。どの件の投稿かを伏せた表で、投稿150件とアカウント100件程度。Claude の自動判定は、このラベルで精度を測る。

## 影響
- 対照群の「の」は、bot・宣伝・まとめ系アカウントが多く入りやすい。除外基準（analysis-plan.md §6）を対照群にも同じように当てる。
- 費用の約9割はタイムラインの取得（280人×100件で約140ドル）。費用を下げるなら、件数を減らすより先に1人あたりの取得件数を減らす案を検討する。
