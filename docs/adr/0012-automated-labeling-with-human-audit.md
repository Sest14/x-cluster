# ADR-0012: ラベル付けは Claude が自動で行い、ユーザーは少数の抜き取り検査と迷った分の判断をする

- 日付：2026-11-19
- 状態：採用（ADR-0010 の「正解ラベルはユーザーが付ける」を置き換え）

## 背景
ラベルが要るのは、起点の投稿約2,000件（関連性と立場）と、第2段階のアカウント約160件（運用の型とジャンル）。全部を人が付けるのは負担が大きすぎる。
一方で、自動判定の誤りは「多少間違っても平均すれば消える」とは限らない。誤りが立場や件によって偏る（例：皮肉の多い側だけ読み違える）と、比較の結果がそのまま歪む。

## 決定
1. **自動ラベル**：Claude が [codebook.md](../codebook.md) に沿って全件にラベルを付ける。モデルの学習はしない（ADR-0007）。
   - どの件の検索から来たかは伏せ、順番を混ぜて判定する。
   - 1件ごとに確信度（高・中・低）を付ける。
2. **自己一致の確認**：無作為に選んだ10%を、順番と言い回しを変えてもう一度判定する。一致率が低い項目は判定基準を見直す。
3. **ユーザーによる抜き取り検査**：件と立場（自動判定の結果）で層化して無作為に選んだ、投稿60件とアカウント30件。件名と自動判定の結果を伏せた表で、ユーザーがラベルを付ける（目安20〜30分）。
4. **ユーザーへの相談**：自動判定で確信度が「低」だったもののうち、最大20件はユーザーが判断する。この20件は精度の測定には使わない。
5. **使い方**
   - 抜き取り検査の結果から、自動判定の正解率とκを、立場と件ごとに出す。
   - 群の間で正解率の差が15ポイントを超えたら「誤りに偏りがある」と報告し、群ごとに補正する。
   - κが0.6未満なら、判定基準書を直してやり直す。
   - 最終的な比率の不確かさには、第1段階ルールの誤り、自動ラベルの誤り、抽出の誤差を、ブートストラップ法でまとめて反映させる。

## 影響
- ユーザーの作業は、約260件から約90件＋相談分20件に減る。
- 抜き取り検査が60件なので、自動判定の正解率の推定には±12ポイント程度の幅が残る。結論が、この幅のなかで変わりうる場合は、断定を避ける。
- 自動ラベルは Claude のモデルや指示が変わると変わりうる。使った判定基準書のコミットハッシュとラベルの結果（仮名IDとラベルだけで、本文は含めない）をリポジトリに残す。
