# ADR-0002: データ取得は公式 X API（従量課金）で行い、スクレイピングはしない

- 日付：2026-11-19
- 状態：置き換え（ADR-0014 により。公式APIは網羅性の検査だけに使う）

## 背景
X の投稿とアカウント情報を、統計を取れる規模で集めたい。X API は2026年2月から従量課金が標準になり、無料枠はない。単価は投稿の取得が1件0.005ドル、ユーザー情報が1件0.010ドル、フォロー関係が1件0.010ドル（2026年11月時点、docs.x.com の料金ページ）。

## 決定
- 公式の X API v2 を、従量課金（Developer Console でクレジットを先払い）で使う。
- ブラウザの自動操作やスクレイピングはしない（規約違反のため）。
- フォロー関係は高くつく（数百人で数千ドル規模）ので取らない。ネットワークは、取得済みの投稿に含まれるリプライ・引用・メンションから作る。
- 予算の上限は `config.json` の `budget_usd` で管理し、推定使用額がそれを超えそうになったらスクリプトが自動で止まる。

## 検討した他の案
- スクレイピング：規約違反で、アカウント凍結のリスクもある。
- フォロー関係のネットワーク：費用が大きすぎる。必要になったら、少数のアカウントに絞ってADRを書いて行う。

## 影響
フォロー関係がないので、「誰が誰を見ているか」はわからない。わかるのは、やり取りの関係だけ。
