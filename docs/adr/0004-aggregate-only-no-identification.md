# ADR-0004: 結果は集計値のみ。個人の特定、アカウント同士の紐付け、魚拓化はしない

- 日付：2026-11-19
- 状態：採用

## 背景
特定の意見を持つ人を名指しで記録して保管すると、界隈の対立の中で晒しの材料になりうる。また X の規約では、削除・編集された投稿は手元でも削除・修正しなければならない。同意のないプロファイリングや追跡、政治的・思想的立場などセンシティブな属性の推定は禁止用途とされている。Developer Console の用途説明にも、集計・仮名化・削除への追従を申告した。

## 決定
- 分析用DB（`analysis.sqlite`）では、アカウントIDと投稿IDをソルト付きハッシュで仮名化する。@名とURLは置き換える。プロフィール内の@名は種類を問わず `@<USER>` にし、本垢を示唆する記述からも紐付けはできないようにする。
- 「このアカウントはどちらの立場か」「このサブ垢は誰の本垢か」を引ける台帳は作らない。
- 削除された投稿を保存し続ける魚拓化はしない。分析が終わったら生データを `purge` で消すか、保持する場合は定期的に `sync` で削除・編集に追従させる。
- 公開・共有するのは集計値だけ。少人数の群は出さない（`methodology.md` §5）。

## 影響
「後から引ける」のは集計と、仮名化されたデータまで。特定のアカウントの履歴はたどれない。
