# ADR-0006: 分析対象のアカウントは、検索条件ごとに層化して無作為抽出する

- 日付：2026-11-19
- 状態：採用

## 背景
件によって投稿者の数が大きく違う。全体から無作為に選ぶと、大きな件のアカウントばかりになり、件どうしを比べられない。投稿数の多い順に選ぶと、声の大きい人に偏る。

## 決定
- `max_accounts`（現在210）を検索条件の数で均等に割り、各条件の投稿者から無作為に選ぶ（乱数シードは `random_seed` = 42）。すでに別の条件で選ばれた人は重複して数えない。
- 全体の比率を出すときは、各層の母集団の大きさ（その条件の投稿者数）で重み付けして戻す。

## 影響
件どうしの比較はしやすくなる。全体の比率は、重み付けを忘れると歪む。
