# ADR-0007: X のデータで機械学習モデルを学習させない

- 日付：2026-11-19
- 状態：採用

## 背景
X の開発者規約は、X のデータでモデルを学習させることを禁止用途に挙げている。Developer Console の用途説明でも、学習・ファインチューニングをしないと申告した。

## 決定
- 立場やサブ垢らしさの判定は、ルール、または学習済みモデルを学習させずにそのまま使う方法（文の埋め込み、トピック分析、学習済みモデルによるゼロショット判定）で行う。
- 人のラベルは、判定の精度を測ることと、比率を補正することにだけ使う。分類器の学習には使わない。

## 影響
専用の分類器を学習させるより精度が落ちる可能性がある。その分、精度を測ったうえで補正し、不確かさを報告する。
