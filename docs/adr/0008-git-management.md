# ADR-0008: コードと文書を Git で管理し、データと秘密情報は入れない

- 日付：2026-11-19
- 状態：採用

## 背景
結果を再現するには、どのコードと設定で出した数字かを特定できる必要がある。一方、トークン、仮名化の鍵、X から取得した投稿は、リポジトリに入れると流出したり、規約上の再配布にあたったりする。

## 決定
- GitHub のプライベートリポジトリ `x-cluster` で、コード（`xc.py`、分析スクリプト）、`config.json`、`docs/` を管理する。
- `.env`、`salt.secret`、`*.sqlite`、`data/` は `.gitignore` で除外する。
- 結果を報告するときは、コミットハッシュを添える（`methodology.md` §2.8）。
- PCの作業フォルダは OneDrive の中にあるので、そこに `.git` は置かない（同期と競合して壊れやすいため）。リポジトリは GitHub が正本で、PC にはファイルだけを反映する。

## 影響
PC側でコードを直接書き換えると、リポジトリとずれる。コードの変更は Claude 側でコミットしてから PC に反映する。
