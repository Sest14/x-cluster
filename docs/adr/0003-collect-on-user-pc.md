# ADR-0003: 収集はユーザーの PC で実行し、分析は仮名化したデータで Claude 側が行う

- 日付：2026-11-19
- 状態：採用

## 背景
Claude の作業環境（クラウド）からは、外部への通信が許可リスト制で `api.x.com` に接続できない。許可リストやネットワークシークレットを設定する画面は、Claude アプリのプロジェクトのチャットからは見つからなかった。

## 決定
- 収集スクリプト `xc.py`（Python の標準ライブラリのみで動く）をユーザーの PC で実行する。
- Claude はPCの `x_cluster` フォルダにファイルを読み書きし、`analysis.sqlite`（仮名化済み）を読み込んで分析する。
- ユーザーが打つコマンドは最小限にする：`py xc.py count`（件数の確認）と `py xc.py run`（収集一式）。

## 検討した他の案
- クラウド環境の許可リストに `api.x.com` を追加する：設定画面が見つからなかった。見つかれば、このADRを置き換えて Claude 側で直接収集する。

## 影響
収集のたびにユーザーの操作が要る。生データはPCに残るので、外に出ないよう管理しやすい。
