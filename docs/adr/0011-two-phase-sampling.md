# ADR-0011: 二段階抽出（二相抽出）にして、「ふだん」は炎上前の期間で測る

- 日付：2026-11-19
- 状態：採用（ADR-0010 の人数・予算・タイムライン取得を置き換え）

## 背景
ADR-0010 の設計（280人×直近100件、約160ドル）には問題が3つあった。
- 費用の約9割がタイムラインの取得で、高すぎる。
- 直近の投稿は炎上の真っ最中のもので、ふだん日常の話をしている人も話題特化型に見えてしまう（測定の偏り）。
- 1件35人では、本垢運用率の95%信頼区間が±17ポイント前後になり、粗すぎる。

件数確認API（counts）は1回0.01ドルで、何件数えても値段が変わらない。

## 決定
**第1段階（広く・安く）**：1件150人＋対照群150人＝1,050人。1人あたり、プロフィール（0.01ドル）と件数確認3回（0.03ドル）。
- `baseline_total`：炎上前の期間（2026-09-15〜10-15）の投稿数（RTを除く）
- `baseline_daily`：そのうち日常語（`config.json` の `daily_words`）を含む投稿の数
- `match_n`：調査期間中に、選ばれた件の検索条件に当たる投稿の数（抽出確率の補正用。ADR-0009）

**第1段階の判定ルール**（事前登録。`phase1_rule`。データを見たあとで変えない）
1. 作成日が2026-10-15以降 → 話題特化型
2. プロフィールに用途の記述（サブ、別垢、本垢、避難、議論用、愚痴、〇〇用、専用）がある → 話題特化型
3. 炎上前の投稿が5件未満 → 低活動
4. 日常語を含む投稿の割合が0.15未満 → 話題特化型。0.15以上 → 汎用型

**第2段階（狭く・深く）**：各群（6件＋対照群）から23人ずつ、第1段階の判定（特化・汎用・低活動）が均等になるように選ぶ（合計161人）。炎上前の期間の投稿を30件ずつ取得する。炎上前の投稿がない人（新しいアカウントなど）は、直近の投稿30件で代える。第2段階のラベル（ADR-0012）で第1段階のルールの的中率を測り、第1段階の全員分の比率を補正する。

**追加の条件（事前登録）**：第2段階で、第1段階のルールの的中率が70%を下回ったら、第2段階を約25ドル分（約160人分）追加する。

**予算**：見積もり約81ドル（1日あたり最低10件取得される分の余分を含む）。上限は90ドル。

## 検討した他の案
- 全員の直近100件を取る（ADR-0010）：高いうえに、炎上の影響で「ふだん」の測定が偏る。
- 全員の炎上前の投稿を20件ずつ取る：1,050人で約115ドルかかる。
- プロフィールだけで判定する：用途を書いていないサブ垢を見落とし、補正しても不確かさが大きく残る。

## 影響
- 本垢運用率の信頼区間は、各群±10ポイント前後（補正込みの目安）になる。
- 話題のクラスタ（ふだん何を話しているか）は、第2段階の約160人×30件から作る。1,050人全員の話題は見られない。
- 件数確認APIの回数制限のため、収集に数時間かかることがある。
- 日常語の一覧と0.15という閾値は事前の決めで、最適とは限らない。その誤差は第2段階の補正で吸収する。
