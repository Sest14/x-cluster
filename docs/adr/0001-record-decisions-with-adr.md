# ADR-0001: 意思決定を ADR で記録する

- 日付：2026-11-19
- 状態：採用

## 背景
検索条件、抽出方法、指標の定義といった選択が、そのまま結果を左右する。あとで「なぜこの数字になったか」を説明できるよう、経緯を残しておく必要がある。

## 決定
- 分析の結果に影響する決定は、`docs/adr/NNNN-タイトル.md` に1件ずつ記録する（雛形は `0000-template.md`）。
- 決定を変えるときは、元のADRを書き換えず、新しいADRで置き換える。元のADRの状態は「置き換え」にする。
- 分析手順の基本は `docs/methodology.md`、今回の分析計画は `docs/analysis-plan.md` に書く。

## 影響
記録の手間は増えるが、定義のすり替えや、結果を見てからの後付けを防げる。
